# LastRowChat – P2P-Chat mit TLS 1.3 / mTLS (Netzsicherheit)

Programmentwurf im DHBW-Modul Netzsicherheit (Teamprojekt): ein Peer-to-Peer-Chat in Python (Standardbibliothek)
mit gegenseitiger Authentifizierung über TLS 1.3 und mTLS.

- `src/` – `hauptprogramm.py` (Einstieg), `cli_ui.py`, `konfig.py`
- `docs/` – `LIESMICH.md` (Anleitung), Sequenzdiagramme, Limitierungen, Aufgabenstellung
- `certs/` – Zertifikate für die Laborumgebung (private Schlüssel nicht versionieren)

```bash
python src/hauptprogramm.py
```
